About this 3D Heritage Prototype

Reconstructed from an archival 1895 photograph of Bedford Square, Tavistock (Devon, UK) using Apple SHARP monocular 3D Gaussian Splatting. The browser edition streams a 500,000-Gaussian web-optimised subset (6.13 MB) directly over static CDN hosting with zero cloud GPU runtime costs.

To inspect the uncompressed 1,179,648-Gaussian master file (66.1 MB .ply) locally, use the Load Local .PLY button in the bottom dock.
